WAKTU EKSEKUSI TERBATAS (50 MENIT): 
Fokus penuh pada eksekusi cepat, efisien, dan self-documenting. Saya ingin kamu langsung membuatkan proyek AI Coding Agent CLI berbasis Node.js/TypeScript.

SYARAT DOKUMENTASI WAJIB (UNTUK OVERHAND KE AI LAIN):
1. Buat file `README.md` yang menjelaskan:
   - Cara install, setup, dan menjalankan proyek.
   - Arsitektur singkat dan struktur direktori.
2. Buat file `PROGRESS.md` yang selalu kamu update di akhir tugas:
   - [ ] Fitur yang sudah Selesai
   - [ ] Fitur yang Belum / Tertunda
   - [ ] Known Bugs / Issues
   - [ ] Catatan untuk AI selanjutnya yang akan melanjutkan proyek ini (Context Handoff).

DESAIN CLI AGENT:
- Memiliki System Loop yang menerima instruksi dari user.
- Fitur Log Summarizer (memotong log terminal > 1000 karakter agar tidak memenuhi konteks).
- Fitur eksekusi terminal/shell bawaan.

LANGKAH PERTAMA (KERJAKAN SEKARANG):
1. Inisialisasi proyek dan buat file `README.md` serta `PROGRESS.md` awal.
2. Tuliskan struktur file `src/` dan langsung buat entry point utama di `src/index.ts`.
3. Mulai koding fungsionalitas utamanya sekarang tanpa banyak bertanya.
